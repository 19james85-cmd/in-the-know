Critical authentication bypass in Ivanti Endpoint Manager — CISA adds to KEV catalog
A critical (CVE-2026-21887, 9.8) in Ivanti Endpoint Manager versions 2024.1–2025.3 allows unauthenticated remote attackers to achieve full administrative access via an authentication bypass in the management API. This has been observed actively exploited by multiple targeting healthcare, financial services, and government networks. added the flaw to its catalog under Emergency Directive 26-04, mandating federal agency by July 7, 2026.
An authentication bypass means attackers can skip the login process entirely — like finding a hidden door that bypasses the keycard reader. A CVSS score of 9.8 out of 10 is near the maximum danger level. Ivanti Endpoint Manager is software organizations use to control all their devices from one place, so gaining access gives an attacker the keys to an entire network. If your organization runs Ivanti products, escalate to IT security immediately.

CVE-2026-21887 — Ivanti EPM authentication bypass granting full unauthenticated admin access
Affected: Ivanti Endpoint Manager 2024.1–2025.3. Attack vector: network, no authentication required. The targets the REST API at /api/v2/auth/token, bypassing all credential checks. Active include unusual POST requests to that endpoint and outbound C2 beaconing to 185.220.101[.]47. Patch: Ivanti Security Advisory ISAI-2026-0127. Federal deadline July 7 — treat as P1 immediately.
A CVE is the universal serial number for security flaws. CVSS 9.8 out of 10 is near-maximum danger. An API is how software components talk internally — this exploit tricks the management API into granting full admin access without a password, like a bank vault that opens when you just knock on the door.

CVE-2026-19944 — Siemens SIMATIC S7-1500 PLC remote code execution via malformed Profinet packets
A critical flaw in Siemens SIMATIC S7-1500 programmable logic controllers allows remote code execution via malformed Profinet protocol packets. This could enable attackers to alter physical industrial processes including manufacturing, water treatment dosing, and power distribution. No available. Siemens recommends immediate network segmentation.
ICS/OT stands for Industrial Control Systems and Operational Technology — the specialized computers running real-world infrastructure. Unlike a data breach that steals files, an ICS attack can cause physical damage. An attacker exploiting this could change chemical dosing in a water supply or shut down a power substation without ever entering the building.
The Hacker NewsCVSS 9.1Patch available
CVE-2026-22301 — Chrome V8 use-after-free enables full browser sandbox escape
Google has emergency-patched a use-after-free in Chrome's V8 JavaScript engine allowing attackers to escape the browser sandbox and execute arbitrary code on the host system. The is delivered via specially crafted web pages — visiting a malicious site is sufficient. Update Chrome to 128.0.6513.119 immediately.
Browsers run web pages in a "sandbox" — an isolated container so malicious code can't escape to harm your computer. A "use-after-free" is a memory error that lets attackers inject their own code. In plain terms: visiting the wrong website could give an attacker complete control of your machine. Check Settings → About Chrome and update if below version 128.0.6513.119.

CVE-2026-20015 — OpenSSH pre-auth race condition enables unauthenticated root on glibc Linux
A race condition in OpenSSH 8.5p1–9.7p1 on glibc-based Linux can be exploited by unauthenticated attackers to achieve root remote code execution in approximately 6–8 hours. The potential impact — full root server compromise — is severe. Patch available in OpenSSH 9.8p1. All Linux distributions running sshd should apply updates immediately.
OpenSSH lets IT administrators securely access servers remotely. "Root" access means the highest administrator level — an attacker with root can do literally anything: delete data, install backdoors, or pivot to other systems. Because glibc is used by almost all Linux systems, this flaw affects a very large number of servers worldwide.

Emergency Directive 26-04 — Ivanti EPM patch mandated across all federal FCEB agencies by July 7
Emergency Directive 26-04 requires all federal civilian executive branch agencies to apply Ivanti's hotfix for CVE-2026-21887 by July 7, 2026, or disconnect all affected systems from federal networks. Agencies must submit verification to CyberScope within 24 hours of remediation. Non-federal organizations are strongly urged to treat this as a P1 remediation regardless of direct applicability.
CISA is the U.S. national cybersecurity agency. An Emergency Directive is the highest-urgency instruction CISA can issue — federal agencies are legally required to comply. Even outside government: when CISA issues an emergency directive, private sector organizations typically face equivalent pressure from cyber insurers and industry regulators within days.

Cyber Incident Reporting Modernization Act clears Senate Commerce — mandatory 24-hour reporting expands broadly
The Senate Commerce Committee has advanced CIRMA, expanding mandatory incident reporting to any organization with $50M+ revenue or 500+ employees. Covered entities must report material cyber incidents and payments to CISA within 24 hours, with a 72-hour supplemental report required. Full Senate vote expected August 2026.
Currently most businesses have no legal obligation to quickly report cyberattacks. This legislation changes that fundamentally. The 24-hour window is very short — you cannot report what you haven't yet detected. Businesses at the proposed threshold should invest in incident detection capabilities now, not after an attack happens.

Cybersecurity DiveAI securityTrend
AI-powered SOC triage cuts MTTD by 67% — but hallucination risk drives mandatory human review gates
Enterprise AI-assisted SOC triage deployments are showing median mean-time-to-detect improvements of 67% versus human-only workflows. However, teams are flagging a critical concern: AI systems generating confident false positives and missing due to model hallucination. CrowdStrike, Palo Alto Networks, and Microsoft are implementing mandatory human-in-the-loop review checkpoints for all high-severity alerts.
A Security Operations Center (SOC) monitors systems around the clock for attack signs. "MTTD" is Mean Time to Detect — faster detection means far less damage. The hallucination problem is that AI sometimes confidently gives wrong answers — an AI that dismisses a real attack as a false alarm may be more dangerous than not having AI at all.
Dark ReadingSupply chainTrend
Open source dependency poisoning attacks surge 312% YoY — npm, PyPI, and Maven Central targeted at scale
A new Sonatype report tracks a 312% year-over-year increase in malicious package uploads to npm, PyPI, and Maven Central. Attackers deploy -embedded packages with names nearly identical to legitimate libraries (typosquatting), gaining access to developer machines and through CI/CD pipelines into production environments. Average survival time before removal: 18 days.
Modern software is built using "packages" — pre-written code libraries so developers don't reinvent the wheel. Dependency poisoning means attackers upload malicious packages with names nearly identical to popular legitimate ones. When a developer accidentally installs the wrong package, attacker code runs on their machine — a stealthy, high-value entry point into organizations.

Cyber insurance premiums declined 8.3% QoQ for the third consecutive period as underwriters cite widespread adoption of , endpoint detection and response, and backup validation. However, 74% of new policies now require minimum security controls as a hard prerequisite for coverage — failure to maintain controls mid-term can void policies retroactively.
Cyber insurance works like car insurance — organizations pay premiums in exchange for coverage if they suffer an attack. The price decline signals improving security posture across insured organizations. Insurers now act as de facto security auditors — requiring specific technical controls as conditions of coverage, not just pricing factors.
